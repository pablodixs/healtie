# Healtie

## Sobre o Projeto

Healtie é uma aplicação web criada para ajudar os usuários a encontrar estabelecimentos de saúde de forma rápida e fácil. O projeto permite que os usuários busquem por locais, visualizem-nos em um mapa interativo e obtenham informações detalhadas sobre cada um.

## Funcionalidades

- **Busca de Estabelecimentos:** Encontre hospitais, clínicas e outros serviços de saúde.
- **Mapa Interativo:** Visualize a localização dos estabelecimentos em um mapa.
- **Campanhas de Saúde:** Mantenha-se informado sobre as últimas campanhas de saúde.
- **Contribuição:** Permite que os usuários adicionem ou atualizem informações sobre os estabelecimentos.

## Tecnologias Utilizadas

- **Next.js:** Framework React para renderização do lado do servidor e geração de sites estáticos.
- **React:** Biblioteca para construir interfaces de usuário.
- **TypeScript:** Superset de JavaScript que adiciona tipagem estática.
- **PandaCSS:** Motor de CSS-in-JS que gera estilos atômicos sob demanda.
- **Mapbox GL JS:** Para mapas interativos e personalizáveis.

## Como Começar

### Pré-requisitos

- Node.js (v20 ou superior)
- npm ou yarn

### Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/healtie.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd healtie
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

## Estrutura do Projeto

A estrutura de arquivos do projeto é organizada da seguinte forma:

- **src/app:** Contém as páginas e rotas principais da aplicação.
- **src/components:** Componentes React reutilizáveis.
- **src/context:** Provedores de contexto React.
- **src/hooks:** Hooks React personalizados.
- **src/assets:** Ativos estáticos, como imagens e ícones.
- **src/interfaces:** Interfaces TypeScript.
- **src/types:** Tipos TypeScript.
- **src/utils:** Funções utilitárias.
